# BarBar — Armenian Speech Transcription Software

## Description

**BarBar** is a software application designed to transcribe Armenian speech into written text.

The application is intended to simplify working with Armenian speech by converting audio recordings, videos, and live speech into text.

## Key Features

- Real-time Armenian speech-to-text transcription.
- Transcription of audio recordings.
- Speech extraction and transcription from videos.
- Displaying the transcribed text on the screen.
- Saving and exporting text in supported formats.

## Objective

The goal of BarBar is to develop a convenient and accessible tool that helps users convert Armenian speech into written text quickly and efficiently.
